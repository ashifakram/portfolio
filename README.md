# Ashif Akram | Portfolio

A modern, high-performance developer portfolio built with React 19, Vite, Tailwind CSS v4, Framer Motion, and Lenis smooth scrolling.

## 🚀 Stack

- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS v4
- **Animations**: Framer Motion
- **Smooth Scroll**: Lenis
- **Icons**: React Icons & Lucide React
- **Forms**: React Hook Form
- **SEO**: React Helmet Async

## 🛠️ Development

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build
```
